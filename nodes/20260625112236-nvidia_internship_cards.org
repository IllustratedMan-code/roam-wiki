* Batch size :drill:

What is the batch size in ML? Why is it important?

[[https://www.youtube.com/watch?v=ad5Wg-abmfk][What are neural Network Batch sizes?]]

The number of training samples processed in one iteration. Small batch
sizes create harsher noisier gradients which increase convergence
speed, while larger batch sizes create smoother gradients, resulting
in a more precise final answer.

Smaller batches are also more memory efficient, but require more
optimizer steps leading to longer training times.
